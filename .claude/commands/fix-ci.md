Please engage the appropriate subagents to fix the recent failures in CI.

Use `gh` to:
1. Check the status of recent workflow runs
2. Identify which jobs/steps are failing
3. Analyze the failure logs
4. Make the necessary code changes to fix the issues
5. Verify the fixes would resolve the failures

Work systematically through each failure until all CI checks pass.

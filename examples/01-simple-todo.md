## Description

This is a simple TODO list showing Lash's basic structure. Perfect for getting started with task tracking in Markdown format.

This example demonstrates:
- Basic task checkboxes with different completion states
- Nested subtasks (parent-child relationships)
- Simple labels for categorization
- Minimal but complete file structure

## Notes

In this example:
- `[x]` marks completed tasks
- `[ ]` marks open tasks
- `[-]` marks waived tasks (not applicable)
- Tasks can be nested up to 3-4 levels deep
- Labels like `#home` help categorize across files
